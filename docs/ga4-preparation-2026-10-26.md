## Audit and implementation
- Source inspection found no GA/GTM tag or analytics CMP. Google verification metadata is not a tracker. Existing SMS/location consent is unrelated and unchanged. Existing GoHighLevel widgets and Lovable visit analytics are not controlled by this new optional-GA4 preference; this work does not claim site-wide third-party compliance.
- Exactly one integration: `src/lib/analytics-runtime.ts`, using a dedicated `avAnalyticsLayer` and one `av-ga4-tag` script. `AnalyticsRuntime` alone sends manual `page_view`. No connector, extra pasted tag or GTM container added.
- `src/lib/analytics-policy.ts` stores the supplied ID and TWO immutable-source gates, both **false**: release authorization and verified stream settings. Consent/localStorage/URL/env cannot open them. Runtime requires exact `https://avdetailing.net`, explicit acceptance and an exact allowlisted public path. Localhost, build/prerender localhost, preview, Lovable hostname, www and HTTP apex are excluded even with gates mocked open.
- Allowlist: 43 existing indexable public paths, using static configuration titles, never live DOM/form titles. `/book`, every booking/payment result/action, account/admin/worker/auth/reset/cancel/rating routes, unavailable RV interior, redirect aliases and unknown paths are excluded. No booking/quote/conversion/click events are added.
- Payload consists only of safe public `page_path`, canonical `page_location`, static `page_title` and a sanitized same-origin public referrer. External/private referrers become empty. Queries/hashes, form fields, contacts, tokens, identifiers and notes are never read into payloads. This deliberately forfeits external campaign/search attribution.
- `send_page_view:false`, `allow_google_signals:false`, `allow_ad_personalization_signals:false`; ads storage/user data/personalization always denied. Basic consent: no Google script/queue/network before opt-in and all gates. The script request has `referrerPolicy=no-referrer`.
- GA configuration also overrides automatic session/engagement page context with sanitized fields. Private history transitions disable collection synchronously before push/replace; popstate disables in a capture listener. React navigation observes the same runtime without a second pageview owner; query/hash-only navigation does not duplicate a pageview.
- Optional nonblocking accept/decline panel on allowlisted public pages, persistent versioned preference, footer settings control, cross-tab updates, no modal until settings are requested. No signup/paywall or booking interruption. Styling uses existing tokens/Button/Dialog. Decline/revoke sets Google's documented `ga-disable-G-YM2RWYQVNS` before any further commands, cancels a pending loader, discards unprocessed queue, and sends no denied-consent cookieless ping. Reaccept reuses the already-loaded tag. Withdrawal stops future collection, not previously sent/in-flight requests; it does not erase Google records/cookies.
