## Audit and implementation
- Source inspection found no GA/GTM tag or analytics CMP. Google verification metadata is not a tracker. Existing SMS/location consent is unrelated and unchanged. Existing GoHighLevel widgets and Lovable visit analytics are not controlled by this new optional-GA4 preference; this work does not claim site-wide third-party compliance.
- Exactly one integration: `src/lib/analytics-runtime.ts`, using a dedicated `avAnalyticsLayer` and one `av-ga4-tag` script. `AnalyticsRuntime` alone sends manual `page_view`. No connector, extra pasted tag or GTM container added.
- `src/lib/analytics-policy.ts` stores the supplied ID and TWO immutable-source gates, both **false**: release authorization and verified stream settings. Consent/localStorage/URL/env cannot open them. Runtime requires exact `https://avdetailing.net`, explicit acceptance and an exact allowlisted public path. Localhost, build/prerender localhost, preview, Lovable hostname, www and HTTP apex are excluded even with gates mocked open.
- Current allowlist: 45 public paths including generic `/book` and `/get-started`, using static configuration titles, never live DOM/form titles. Booking/payment result/action, account/admin/worker/auth/reset/cancel/rating routes, unavailable RV interior, redirect aliases and unknown paths remain excluded. Part 2 added saved-booking/API-accepted-quote events and separate contact clicks; see the current SEO report's dictionary.
- Payload uses safe public `page_path`, canonical `page_location`, static `page_title` and sanitized `page_referrer`. Same-origin referrers retain only exact allowlisted canonical public paths. External search referrers retain **HTTPS origin only**, from an exact hostname allowlist: `google.com`, `www.google.com`, `google.co.uk`, `www.google.co.uk`, `google.ca`, `www.google.ca`, `bing.com`, `www.bing.com`, `duckduckgo.com`, `www.duckduckgo.com`, `yahoo.com`, `www.yahoo.com`, `search.yahoo.com`. No suffix matching; credentials, nonstandard ports, HTTP, lookalikes, private/unknown local paths and all other external sources are omitted. ALL external paths/queries/hashes and user information are stripped. No raw UTMs/form values or source labels inferred from queries.
- **First-consented hit:** sanitize arrival once in memory on canonical public entry. Public navigation before acceptance (including aircraft→`/book`) cannot replace that arrival with `previousPublic`; send only the current page once when consent/loading/gates permit. Empty/direct arrival stays empty. Subsequent public hits use safe public navigation referrers. Explicit decline or any private/unknown transition clears entry context; source never resurrects after returning from private routes. No raw referrer persistence, private history/event queue or pre-consent Google traffic. Lead/contact events share their current page hit's sanitized referrer.
- Search-origin coverage is deliberately limited, **not complete attribution**: unlisted regional search domains (for example Google Germany), other search engines, other external sources, browser-suppressed referrers and nonconsenting traffic are omitted. Referrer omission is not proof of direct traffic; no campaign attribution, keyword capture or ranking/lead-growth claim. Actual GA4 channel/source interpretation still requires authorized stream/Realtime/report verification.
- `send_page_view:false`, `allow_google_signals:false`, `allow_ad_personalization_signals:false`; ads storage/user data/personalization always denied. Basic consent: no Google script/queue/network before opt-in and all gates. The script request has `referrerPolicy=no-referrer`.
- GA configuration also overrides automatic session/engagement page context with sanitized fields. Private history transitions disable collection synchronously before push/replace; popstate disables in a capture listener. React navigation observes the same runtime without a second pageview owner; query/hash-only navigation does not duplicate a pageview.
- Optional nonblocking accept/decline panel on allowlisted public pages, persistent versioned preference, footer settings control, cross-tab updates, no modal until settings are requested. No signup/paywall or booking interruption. Styling uses existing tokens/Button/Dialog. Decline/revoke sets Google's documented `ga-disable-G-YM2RWYQVNS` before any further commands, cancels a pending loader, discards unprocessed queue, and sends no denied-consent cookieless ping. Reaccept reuses the already-loaded tag. Withdrawal stops future collection, not previously sent/in-flight requests; it does not erase Google records/cookies.
